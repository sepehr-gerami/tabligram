#

«یک تبلیغ، چندین پیج اینستاگرام». این پروژه فقط فرانت‌اند است و داده‌ها نمونه‌اند.

## اجرا در VS Code

نیازمندی: Node.js نسخهٔ ۲۰ یا بالاتر.

```bash
npm install
npm run dev        # http://localhost:3000
```

بیلد نهایی و بررسی TypeScript:

```bash
npm run typecheck
npm run build && npm start
```

## مسیرها

| مسیر | محتوا |
| --- | --- |
| `/` | صفحهٔ اصلی |
| `/campaigns/new` | ثبت تبلیغ، پیش‌نمایش و فهرست سفارش‌های ثبت‌شده |
| `/publisher/dashboard` | پنل صاحبان پیج (ثبت/ویرایش پیج و مدیریت پیشنهادها) |
| `/admin` | پنل مدیریت |

## نکته‌های مهم

- داده‌ها در `lib/data.ts` هستند و تغییرات در `localStorage` مرورگر ذخیره می‌شوند.
  برای بازگشت به داده‌های اولیه، دکمهٔ «بازنشانی داده‌های نمونه» در فوتر را بزنید.
- «ورود»، «ثبت‌نام» و جابه‌جایی نقش‌ها نمایشی است و احراز هویت واقعی نیست.
- پنل مدیریت سیستم امنیتی ندارد و هر کسی با آدرس آن را می‌بیند.
- پرداخت، API اینستاگرام، بک‌اند و هوش مصنوعی در این نسخه وجود ندارد.
- فایل آپلودشده فقط برای پیش‌نمایش استفاده می‌شود و ذخیره نمی‌شود (فقط نام فایل ثبت می‌شود).

## ساختار

```
app/                 مسیرها (App Router)
components/ui        کامپوننت‌های پایه به سبک shadcn/ui
components/layout    هدر، فوتر، پوستهٔ پنل‌ها
components/home      بخش‌های صفحهٔ اصلی
components/campaigns فرم ثبت تبلیغ و انتخاب پیج
components/shared   کارت/جزئیات پیج، ریل و نمایشگر استوری
components/publisher پنل صاحبان پیج
components/admin     پنل مدیریت
lib/                 داده، store، اعتبارسنجی، ابزارها
types/               تایپ‌ها
```

## انتخاب پیج و استوری‌ها

- در `/campaigns/new` بخش «انتخاب پیج پیشنهادی (اختیاری)» فهرست پیج‌های تأییدشده (`advertiserPages` در `lib/pages.ts`) را نشان می‌دهد.
  انتخاب پیج دسته‌بندی/محدوده/نوع انتشار فرم را پر می‌کند و تعرفهٔ همان پیج در پیش‌نمایش دیده می‌شود؛ فقط شناسهٔ آن به‌صورت `selectedPageId` ذخیره می‌شود و تخصیص واقعی پیج همچنان کار مدیر است.
- استوری‌ها از `components/shared/story-rail.tsx` و `story-viewer.tsx` نمایش داده می‌شوند و صاحب پیج آن‌ها را از `story-manager.tsx` ثبت/غیرفعال/حذف می‌کند. فایل استوری هم فقط پیش‌نمایش است (object URL) و پس از بازآوری صفحه از بین می‌رود.
- مدل‌های مشترک پیج در `components/shared/page-card.tsx` و `page-detail-dialog.tsx` هستند و هم در صفحهٔ اصلی و هم در فرم تبلیغ استفاده می‌شوند.

## بنر تبلیغاتی صفحهٔ اصلی

- `components/home/ad-banner-carousel.tsx`: بنر به سبک استوری اینستاگرام (نوار پیشرفت، کشیدن/کیبورد، توقف خودکار هنگام hover و focus، احترام به `prefers-reduced-motion`).
- اسلایدها از کمپین‌های «در حال اجرا» و «تکمیل‌شده» ساخته می‌شوند (`lib/banners.ts`)؛ اگر مدیر وضعیت یک کمپین را «در حال اجرا» کند، در بنر دیده می‌شود.
- پس‌زمینهٔ تم اینستاگرام: `components/home/instagram-backdrop.tsx`. برای برداشتن آن، `<InstagramBackdrop />` را از `hero.tsx` حذف کنید.
- لایک‌ها و نظرها نمونه‌اند و واقعی نیستند.

## تغییر رنگ‌ها و فونت
